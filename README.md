# x_bot

Grok-driven X audience builder for my games (mobile + board game).

- **Grok** (Automations + GitHub connector) scouts X, drafts posts and replies, and runs a weekly learning review.
- **This repo** is the shared memory (`brain/`), approval queue (`queue/`), and results ledger (`ledger/`).
- **GitHub Actions** (Phase 1) post approved originals via the X API.
- **You** approve by merging PRs and work a ~15 min daily engagement issue. Likes, follows and replies stay human — X bans automating them.
